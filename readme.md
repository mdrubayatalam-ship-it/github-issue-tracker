<!-- Questions -->

1️⃣ What is the difference between var, let, and const?
2️⃣ What is the spread operator (...)?
3️⃣ What is the difference between map(), filter(), and forEach()?
4️⃣ What is an arrow function?
5️⃣ What are template literals?

<!-- Answers -->

1. Var is mostly used for global or function scope.It can be modified within its scope
   let is normally used for blocked scope. It can be modified but can not be re-declared in the same scope.
   const is also used in a blocked scope. It cannot be modified after initialized.


2. Spread Operator is a feature of JS ES6 which can individually separate the element of an array or object to use in another purpose.

3. map() : it is a method of array which transforms each elements in the array.it returns a new array of exact same length with transformed values.
   filter() : it is also a method of array which selects the item that pass a specific condition. it returns a new array which is containing only the item that match the condition.

   forEach() : this method executes a function for each item.


4. An arrow function is a Short form of defining a function.


5. Template literals is usually used for dynamic changes according to our API data.
